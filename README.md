# Nike Design 3

Fan-style static catalog (Slovenian), inspired by sneaker and streetwear shops.

## Pages
- `index.html` — home
- `dunks.html` — Dunk models
- `basketball.html` — signature basketball shoes (Luka, LeBron, KD, Giannis, Kobe)
- `majice.html` — tees (click an image to zoom)
- `oprema.html` — hoodies and other gear
- `hypebeast.html` — hypebeast culture
- `supreme-stores.html` — Supreme store locations

Demo only. Product photos are Unsplash stock, not official brand assets. Not affiliated with Nike, Jordan Brand, Louis Vuitton, or Supreme.
